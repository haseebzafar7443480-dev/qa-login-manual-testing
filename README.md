# Login Page Manual Testing

A beginner QA project showing manual testing skills: test cases and bug reports for a login page.

## Files
- `test_cases.csv`: 12 test cases (positive, negative, validation, security, usability)
- `bug_reports.md`: example bug reports with steps, expected and actual results

## Skills shown
- Writing clear test cases
- Positive and negative testing
- Input validation and basic security checks
- Writing professional bug reports (severity, priority, steps to reproduce)

## How to use
Open `test_cases.csv` in Excel or Google Sheets, run each test on any login page, then fill in Actual Result and Status (Pass / Fail).
